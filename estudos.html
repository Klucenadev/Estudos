outras formatações

codigo-fonte

codigo-fonte usado para dar o mesmo espaço entre as letras. obs: pode ser usado sem a tag paragrafo

o comando document.getElementByID('teste') é escrito em javascript (sem codigo-fonte)

o comando document.getElementByID('teste') é escrito em javascript (com codigo-fonte)

pre-formatação

pre-formatação é utilizado quando se quer ter indentação. obs: da pra ser usado em onjunto com o codigo fonte

public class projeto1 { public static void main(String[] args) { System.out.println("projeto1"); } (sem pre-formatação) 
public class projeto2 {
        public static void main(String[] args) {
    System.out.println("projeto2");

    }
}
    (com pre-formatação)
